# Changelog

Все заметные изменения проекта фиксируются здесь, чтобы на GitHub было понятно, чем отличается каждая сборка.

## 3.0.0 - 2026-06-08

### Стабильная скорость

- Safe packet-профиль снижен до устойчивого уровня и теперь тоже масштабируется adaptive mining controller.
- Speed guard получил гистерезис: мелкие колебания рядом с целью не вызывают лишние перезаходы.
- При плохих подтверждениях packet-break бот заранее включает packet-safe режим до кика `too many packets`.
- Offline watchdog больше не пересоздаёт bot instance поверх активного reconnect.
- Проверено на реальном сервере с рабочим конфигом: 15 минут без `too many packets` и reconnect, скорость `732-748 б/м`.

## 2.1.0 - 2026-06-08

### Стабильность

- Добавлен адаптивный packet governor для safe/recovery режима после `too many packets`.
- Добавлен adaptive mining controller для устойчивого packet-break лимита по реальным подтверждениям блоков.
- Speed guard теперь сначала делает rescan/очистку stale pending и soft restart добычи, а reconnect оставляет последней ступенью.
- Snapshot получил блок `performance` с effective/raw скоростью, peak, packet mode и причиной просадки.
- BotFilter/chat-captcha теперь требует evidence из реального server-message/chat packet.

### Обновления и UI

- Центр обновлений получил online/fallback/cache режимы.
- На пульте добавлен компактный диагноз скорости и packet mode.
- В логах добавлен фильтр `Важное / Всё`.
- Android release build больше не создаёт fallback/CI-подпись.

## 2.0.0 - 2026-06-06

### LimboFilter

- Бот адаптирован под исходную логику LimboFilter 1.1.18.
- Fall-проверка строится по server `position` packet и формуле LimboFilter, без подмены координат шахты.
- Исправлен реальный случай `Y=1024`: бот больше не нормализует его в `512`.
- Добавлен строгий локальный emulator LimboFilter и тесты формулы падения.
- Чат/карта-капча логируется и уводит бота в 30-минутную паузу без попыток авто-OCR.

### Сборка

- GitHub Release собирает Windows installer и Android APK.
- Portable-сборка больше не публикуется в релизе 2.0.0.

## 1.0.3 - 2026-06-03

### Вход на сервер

- Полностью переработана логика входа через меню.
- Бот больше не кликает слоты 10 и 13 вслепую в любом открытом окне.
- Вход теперь работает как state-machine: открыть меню, выбрать "Скайблок", выбрать "Второй Скайблок", дождаться подсерверa.
- Окна распознаются по заголовку и тексту предметов в слотах.
- После `client timed out` вход восстанавливается быстрее и не застревает на длинном `menu-attempt-limit`.
- При зависании в лобби бот пересоздаёт подключение коротким recovery-циклом, а не ждёт 1-3 минуты.

## 1.0.0 - 2026-06-03

### Главное

- Собрана текущая локальная версия ProstoCraft Bot Studio после отката лишних экспериментов скорости.
- Оставлена стабильная логика добычи с packet-break движком и защитой от лишнего спама диагностикой.
- Добавлен режим отладки в настройках: по умолчанию выключен, а подробные `[DIAG]` появляются только при включении.
- Логи в интерфейсе показывают свежие события сверху, чтобы не прокручивать файл вниз.
- Упрощён раздел настроек: убраны лишние, сложные и нерабочие параметры, оставлены рабочие пользовательские опции.

### Стабильность

- Кнопка генератора нажимается после входа/перезахода на подсервер.
- Улучшены проверки рабочей позиции, чтобы координата шахты не считалась спавном.
- Runtime-логи очищаются между сессиями, чтобы в файле оставался только последний запуск.
- Проверки источников синхронизируют desktop, Android assets и Cordova-копии.

### Сборка

- Windows-релиз настроен в двух вариантах:
  - `ProstoCraft Bot Studio-Setup-1.0.0.exe` - установщик.
  - `ProstoCraft Bot Studio-Portable-1.0.0.exe` - portable-версия без установки.
- Добавлен GitHub Actions workflow для автоматического создания Release по тегу `v*`.
