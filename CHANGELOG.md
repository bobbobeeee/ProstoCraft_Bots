# Changelog

Все заметные изменения проекта фиксируются здесь, чтобы на GitHub было понятно, чем отличается каждая сборка.

## 1.0.2 - 2026-06-03

### GitHub Release

- Имена файлов релиза приведены к одному формату без пробелов, чтобы GitHub assets и `SHA256SUMS.txt` совпадали.
- Актуальные файлы скачивания:
  - `ProstoCraft.Bot.Studio-Setup-1.0.2.exe` - установщик.
  - `ProstoCraft.Bot.Studio-Portable-1.0.2.exe` - portable-версия без установки.

## 1.0.1 - 2026-06-03

### GitHub Release

- Исправлен релизный workflow: `electron-builder` больше не пытается публиковать файлы сам во время сборки.
- GitHub Release публикуется отдельным шагом после успешной сборки.
- Windows runner закреплён на `windows-2022` для более предсказуемой сборки.
- Текущий релиз скачивается отдельными файлами:
  - `ProstoCraft Bot Studio-Setup-1.0.1.exe` - установщик.
  - `ProstoCraft Bot Studio-Portable-1.0.1.exe` - portable-версия без установки.

## 1.0.0 - 2026-06-03

### Главное

- Собрана текущая локальная версия ProstoCraft Bot Studio после отката лишних экспериментов скорости.
- Оставлена стабильная логика добычи с packet-break движком и защитой от лишнего спама диагностикой.
- Добавлен режим отладки в настройках: по умолчанию выключен, а подробные `[DIAG]` появляются только при включении.
- Логи в интерфейсе показывают свежие события сверху, чтобы не прокручивать файл вниз.
- Упрощён раздел настроек: убраны лишние, сложные и нерабочие параметры, оставлены рабочие пользовательские опции.

### Стабильность

- Кнопка генератора нажимается после входа/перезахода на подсервер.
- Улучшены проверки рабочей позиции, чтобы координата шахты не считалась спавном.
- Runtime-логи очищаются между сессиями, чтобы в файле оставался только последний запуск.
- Проверки источников синхронизируют desktop, Android assets и Cordova-копии.

### Сборка

- Windows-релиз настроен в двух вариантах:
  - `ProstoCraft Bot Studio-Setup-1.0.0.exe` - установщик.
  - `ProstoCraft Bot Studio-Portable-1.0.0.exe` - portable-версия без установки.
- Добавлен GitHub Actions workflow для автоматического создания Release по тегу `v*`.
