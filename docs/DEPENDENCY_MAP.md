# Dependency Map

Phase 1 artifact, updated after Phase 7. This map documents the current dependency surface after
the `bot.js`, renderer, Electron main-process, release-tooling, and initial checkJs extractions. It is intentionally descriptive
only; it does not propose new module boundaries.

## Runtime Entry Points

| Entry point                                           | Runtime                                                    | Direct local dependencies                                                   | Notes                                                                                                 |
| ----------------------------------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `bot.js`                                              | CLI/headless, Electron child runtime, Android Node runtime | `monitoring.js`, `stability-center.js`, `speed-guard.js`, `runtime-core/*`  | Runtime orchestrator. Exports a host-controlled runtime API, but otherwise starts bots when loaded.   |
| `desktop/main.js`                                     | Electron main process                                      | `desktop/main/app-bootstrap.js`                                             | Thin Electron bootstrap entry point.                                                                  |
| `desktop/main/*.js`                                   | Electron main process                                      | `update-service.js`, `stability-center.js`, `runtime-core/config-schema.js` | Owns window/tray, runtime child process, update flow, config IO, and secured IPC handlers.            |
| `desktop/preload.js`                                  | Electron preload                                           | none                                                                        | Exposes `window.botStudio` IPC facade.                                                                |
| `desktop/renderer/bridge.js`                          | Browser/Electron/Cordova renderer                          | embedded default config and native bridges                                  | Normalizes desktop, Android, and fallback bridge APIs into `window.botStudioBridge`.                  |
| `desktop/renderer/app.js`                             | Browser renderer                                           | `window.botStudioBridge`, `window.BotStudio*` modules                       | Thin renderer shell: state, render queue, bootstrap, shared app API.                                  |
| `desktop/renderer/app-*.js`                           | Browser renderer                                           | `window.BotStudioApp`, `window.BotStudio*` modules                          | Feature modules for settings schema, dashboard, bots, settings, logs, updates, mobile actions.        |
| `mobile-cordova-src/nodejs-project/mobile-runtime.js` | Android Node runtime                                       | `update-service.js`, `stability-center.js`, `bot.js`, `package.json`        | Cordova bridge host for the bot runtime. Loads `bot.js` in host-controlled mode.                      |
| `scripts/build-cordova-android-release.js`            | Release tooling                                            | `scripts/android-release/build-pipeline.js`                                 | Thin Android release build entry point.                                                               |
| `scripts/android-release/*.js`                        | Release tooling                                            | filesystem/process only                                                     | Android release context, Gradle runner, Cordova Android patching, signing, and generated Java source. |
| `scripts/sync-android-assets.js`                      | Generated asset sync                                       | filesystem/path only                                                        | Copies renderer assets to native Android assets.                                                      |
| `scripts/sync-cordova-app.js`                         | Generated asset sync                                       | filesystem/path only                                                        | Copies renderer/runtime files to Cordova `www`.                                                       |

## Characterization Test Targets

The Phase 1 golden-master tests lock down:

- public export names for shared modules, `runtime-core/*`, Electron main-process helpers, and release-tooling helpers;
- browser renderer module loading order and key `window.BotStudio*` APIs;
- desktop preload IPC channels, main-process IPC allowlist, payload validators, and external URL guard;
- Android release helper behavior for versioning, process spawning, APK selection, generated service source, and NodeJS plugin patching;
- representative reconnect, BotFilter, LimboFilter, speed guard, health, timeline, update, and mining-controller outputs;
- the host-controlled `bot.js` runtime API shape without starting bots;
- generated asset synchronization through the existing source hygiene check.
