# Инструкция пользователя

## Что это

ProstoCraft Bot Studio - desktop-приложение для запуска и настройки Mineflayer-бота ProstoCraft.

## Как скачать

Открой страницу GitHub Releases:

https://github.com/merrobocop/ProstoCraft_Bots/releases

Скачай один из файлов:

- `ProstoCraft.Bot.Studio-Setup-1.0.3.exe` - если нужна обычная установка.
- `ProstoCraft.Bot.Studio-Portable-1.0.3.exe` - если нужно запустить без установки.

## Первый запуск

1. Запусти приложение.
2. Открой раздел настроек.
3. Укажи ник, сервер и рабочие координаты.
4. Проверь координату кнопки генератора.
5. Нажми запуск бота.

## Режим отладки

По умолчанию режим отладки выключен, чтобы логи не раздувались.

Включай его только когда нужно понять причину вылета, падения скорости или проблем с координатами. После включения в логах появятся подробные строки `[DIAG]`.

## Логи

В интерфейсе свежие события показываются сверху.

Локальный runtime-файл:

```text
%APPDATA%\autominerv2\runtime\bot.log
```

## Проверка скорости

В статистике смотри строку `RATE/MIN` или скорость конкретного бота в `б/с`.

Пример:

```text
Скорость: 12.2 б/с
```

Это примерно `732 блока/мин`.
