# ProstoCraft Bot Studio

Приложение для запуска, настройки и наблюдения за ProstoCraft mining bots на Windows и Android.

## Скачать последнюю версию

[Открыть страницу скачивания](https://github.com/bobbobeeee/ProstoCraft_Bots/releases/latest)

Доступны два варианта:

- `ProstoCraft.Bot.Studio-Setup-2.0.3.exe` - установщик для Windows.
- `ProstoCraft.Bot.Studio-Mobile-2.0.3.apk` - APK для Android.

## Возможности

- запуск одного или нескольких ботов;
- настройка сервера, аккаунта, координат шахты и кнопки генератора;
- компактные вкладки для управления, ботов, логов/чата и дополнительных функций;
- тёмный интерфейс, адаптированный под ПК и телефон;
- режим отладки для подробных диагностических логов;
- защита от частых просадок скорости через настраиваемый speed guard;
- центр состояния с диагнозом сети, reconnect и скорости копания.

## Первый запуск

1. Установите приложение или откройте APK на Android.
2. Откройте `Ещё` -> `Настройки`.
3. Укажите ник, сервер и рабочие координаты.
4. Проверьте координату кнопки генератора и слоты меню.
5. Запустите бота с вкладки `Пульт`.
