# ProstoCraft Bot Studio 2.0.2

Тестовый релиз для проверки центра обновлений через GitHub.

## Что нового

- Версия поднята до `2.0.2`, чтобы установленная `2.0.1` увидела доступное обновление.
- Логика бота и настройки копания не менялись.
- Центр обновлений должен показать новый installer/APK, скачать файл и проверить его по `SHA256SUMS.txt`.

## Что скачать

- `ProstoCraft.Bot.Studio-Setup-2.0.2.exe` - обычный установщик Windows.
- `ProstoCraft.Bot.Studio-Mobile-2.0.2.apk` - Android APK.
- `SHA256SUMS.txt` - контрольные суммы файлов.
