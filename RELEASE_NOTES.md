# ProstoCraft Bot Studio 2.0.3

Исправление установки обновлений на Android.

## Что нового

- При нажатии `Установить` Android сразу открывает разрешение `Установка неизвестных приложений` для ProstoCraft, если оно выключено.
- После возврата из настроек приложение повторно открывает системный установщик APK.
- Уведомление в шторке остаётся с кнопкой `Установить`, чтобы можно было продолжить после выдачи разрешения.
- Логика бота и настройки копания не менялись.

## Что скачать

- `ProstoCraft.Bot.Studio-Setup-2.0.3.exe` - обычный установщик Windows.
- `ProstoCraft.Bot.Studio-Mobile-2.0.3.apk` - Android APK.
- `SHA256SUMS.txt` - контрольные суммы файлов.
